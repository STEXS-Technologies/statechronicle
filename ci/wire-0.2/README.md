# Original-release wire corpus

`history.json` was generated by `wire_producer.rs` linked exclusively against
`c418e98b91720188158c531cd5c2c4b8ab71cbcf`, using that release's unchanged
lockfile and test composition root. `provenance.json` identifies the producer
source hash, corpus hash and execution evidence. The history includes mint and
transfer events, a signed commit, final projection, inclusion and absence
proofs, and original canonical byte arrays for events, signing input and proofs.

The new `wire_compat.rs` reader checks those bytes without generating new
expectations, replays the committed root, verifies the original signature and
proofs under an independently supplied test key, and rejects wrong-key and
wrong-signer substitutions. This is one pinned historical commit, not an
assertion of current-head freshness, disk durability or full schema coverage.
Released custom-domain JSON goldens and recovery tests are separately frozen in
the external consumer matrix.

Initial creation used `scripts/refactor_compat.py --produce-wire`. That flag
refuses candidate-only generation and refuses to overwrite an existing corpus.
Ordinary compatibility runs only read the corpus. Add separate new fixtures
for new behavior; never replace these expectations with candidate output.
